# 🌟 Digital Vision Board

A modern and responsive web application that helps users visually organize their goals, dreams, and future plans.

## 🚀 Features
- User login & signup system
- Add vision with image, date and description
- Edit and delete goals
- Responsive UI for mobile and desktop
- Attractive modern design
- Local storage data persistence

## 🛠 Technologies Used
- React.js
- HTML5
- CSS3
- Bootstrap
- JavaScript
- LocalStorage API

## 🎯 Purpose of Project
This project was built to practice frontend development concepts such as component architecture, routing, form handling, state management, and responsive UI design.
